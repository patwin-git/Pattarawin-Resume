# Assets

Place your profile photo here as **`profile.jpg`**.

Recommended: a portrait-orientation image around **800 × 1000 px** (4:5 ratio), JPG or PNG.

After adding the file, open `index.html` and, inside the `.photo-frame` block, uncomment this line:

```html
<img src="assets/profile.jpg" alt="Portrait of Pattarawin Teerachai" />
```

…then delete (or leave hidden behind it) the `.photo-placeholder` block. The image will fill the framed card automatically.
